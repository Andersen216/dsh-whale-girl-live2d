## ③ 发之前/之后的注意（B 站跟小红书规则不一样）

| 事项 | 说明 |
| --- | --- |
| **先私信、再评论** | 直接跑到人家视频底下打广告容易招反感；先说一句"我做了个二创"，再评论就顺理成章 |
| **评论里别放完整链接** | B 站会折叠/吞外链。写「GitHub 搜 Andersen216/dsh-whale-girl-live2d」最稳 |
| **评论只发一条** | 别在同一个视频下反复刷，也别去多个视频刷；作者回复了要及时回应 |
| **图片只放动态** | B 站评论带不了图，所以两张图放在你自己的动态里，评论里写"教程在我主页动态" |
| **@ 作者** | 动态里 @氵六青，让他能看到；同时 @上善无形、@ZipZipPipe 更完整（找不到账号就写名字） |
| **非商业** | 别开充电专属、别挂商品、别接推广 —— 素材是 CC BY-NC-SA 4.0，收费就违约了 |
| **被要求撤下就撤** | 作者如果说不希望这样用，立刻下架，这是二创的基本礼貌（也写进评论里了） |
