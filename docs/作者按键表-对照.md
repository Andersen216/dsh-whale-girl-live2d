# 原作者按键表 → 桌宠菜单 对照

桌宠不是我们自己瞎编动作，而是**照作者本人的设计**来的。
原始素材里有两份「作者说怎么用」的文件（`DS鲸鱼娘/` 目录）：

| 文件 | 里面是什么 |
| --- | --- |
| `按键表.txt` | 作者写的中文按键说明（哪个键干什么、什么前置条件） |
| `extracted/*/c_0120.vtube.json` | VTube Studio 的模型配置，**52 条热键**的原始定义（名字 / 类型 / 文件名 / 按键） |

`c_0120.vtube.json` 里的 `Action` 字段把动作分成三类，我们的菜单就是按它分页的：

| 作者的写法 | 含义 | 桌宠里放哪 |
| --- | --- | --- |
| `ToggleExpression` | 开关式：开着就一直挂 | 「装饰」或「场景」页（**一直存在**，再点一下收） |
| `TriggerAnimation` | 一次性动画：播完就结束 | 「动作」页（**演一次就消失**） |
| `RemoveAllExpressions` | 按键归位：全部清掉 | 「设置」页的**一键重置所有状态** |

`DeactivateAfterKeyUp: true` 的那几条（点菜按下 / 画笔 / 挤）是作者设计的
**「按住左键时才有」**——所以我们把「点菜按下 + 画笔」当成常态道具（IDLE_PROPS），
跟人家按住鼠标时的样子一致。

## 4. 表情（作者的表情热键）

`Alt+Q/W/E/R/T/Y/U/I/O/P/S/D/F/G/H/J/K/L/Z/X/C/V/B/N/M` 一共 24 个。
桌宠的「表情」页按**表情**去重（一个表情只出一个按钮，例如「星星眼」同时对应
好奇/兴奋/凑近看，就只出现一次），点一下她会说一句对这个表情的话。

| 作者有、桌宠不上 | 原因 |
| --- | --- |
| 呆呆眼 | 主人点名不要 |
| 晕晕 | 主人点名不要（圈圈眼） |

**闭眼口水**（`Alt+T`）是作者的正经表情，桌宠保留。

## 5. 归位

| 原作者热键 | 桌宠 |
| --- | --- |
| `PageDown+PageUp` 按键归位（`RemoveAllExpressions`） | 设置页 · **一键重置所有状态** |

重置换算成一件事：**回到「本子 + 笔 + 平常脸」**——
所有道具（含手机、魔爪、桌布、贴纸、眼镜）全部摘掉，所有表情归零，
干活轮播也停掉（否则几秒后又被推回工作脸，看起来就像「重置没生效」）。

## 冲突与覆盖是怎么避免的

1. **一层只有一个写者**：`applyRig` 里每个参数都过一遍「独占裁决」，
   同一帧同一个参数只会有一个来源（表情优先于道具），
   有冲突时记在 `state.exclusive.skipped` 里，可以直接看到。
2. **动作自带表情时不加压脸**：`mood: null` 的动作（自拍、喷水、番茄酱、猫爪动画…）
   把脸交还给动画本身，不会再盖一张表情上去——这就是「不要覆盖」。
3. **互斥分组**：眼镜 `glasses`、贴纸 `sticker`、桌布 `cloth`、发型 `hair`、魔爪 `claw`，
   同组只留一个。
4. **前置依赖**：白魔爪 → 粉魔爪；手机换色 / 自拍 / 快速自拍 → 手机模式。
   点的时候自动补前置，不会出现「素材没亮所以看不出效果」。
5. **一次性动作只走 override 层**：不写进 `userProps`，所以到点必然自己消失，
   不会出现主人抱怨过的「蛋包饭永久停在桌上」。
