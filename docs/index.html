🐋 DS 鲸鱼娘

DSH（DeepSeek Harness）里的 Live2D 桌宠 —— 她不是贴图：思考、查资料、写文件、报错、收工，她都在跟着 agent 的真实状态动。点一下就能直接跟 agent 说话。

⬇️ 下载桌面版（macOS） GitHub 仓库

先弄清楚：只有一套插件，两种用法

插件只有一个（dsh-whale-girl-live2d）。装一次，网页版和桌面版共用同一份 —— 模型、动作、表情、联动、菜单、钱包全在插件里。
桌面版只是额外下载一个 1.4 MB 的 macOS 外壳 App，把同一页放进桌面上的独立窗口。 它不是第二个插件。
必装 · 全平台

🖥 网页版

  • 她住在 DSH Web 界面右下角
  • Windows / macOS / Linux 都能用
  • 只需要装插件，一条命令
  • 浏览器标签页开着就能看到她
可选 · 仅 macOS

🐋 桌面版

  • 她住在你的桌面上：透明、无边框、永远置顶
  • 点击穿透 —— 鼠标压在她身上才收事件，不挡你干活
  • 拖她 = 拖窗口；收起会变成贴边悬浮球
  • 菜单栏 🐋 控制；浏览器可以关掉

安装：两条路都行

🅰 先网页版，再桌面版（推荐）

  1. 装插件：
    dsh plugin --profile web add github:Andersen216/dsh-whale-girl-live2d
  2. 重启 DSH，然后刷新页面 —— 右下角出现她 = 网页版成功
  3. 自检：访问 http://127.0.0.1:3080/dsh-pet/pet.js，返回 401 就是挂上了
  4. 下载上面的 macOS zip → 解压 → 把 DS 鲸鱼娘桌宠.app 拖进「应用程序」
  5. 双击打开 —— 菜单栏会出现 🐋，她就落在你桌面上了

🅱 先桌面版，再网页版（也可以）

  1. 先下载 zip、拖进「应用程序」、双击 —— 窗口里会显示「🐋 正在找 DSH…」
    这是正常的，因为插件还没装
  2. 再按 🅰 的第 1~3 步装插件并重启 DSH
  3. 她自己出现，不用重启 App（App 每 5 秒自动重试一次）
⚠️ 顺序无所谓，但少了插件一定不行：桌面 App 本身不带模型、不带联动（所以它只有 1.4 MB）， 它只是一个窗口，内容全在插件里。Windows / Linux 用户用网页版即可，功能完全一样。

她长什么样

出问题怎么查

桌面 App 里显示「正在找 DSH…」

说明插件没装、DSH 没跑，或者插件被停用了。先确认 curl -s -o /dev/null -w "%{http_code}" http://127.0.0.1:3080/dsh-pet/pet.js 返回 401。

返回 404（她也整个消失了）

插件没被注册，或者在插件设置里被停用了。检查 ~/.dsh/profiles/web/cordis.patch.yml 里有没有 - id: dsh-live2d-pet 加 disabled: true，有就把这两行删掉再重启 DSH。

双击 App 好像没反应

它是无 Dock 图标的后台型 App，可能已经在跑了 —— 看菜单栏右上角的 🐋；再双击一次会把窗口叫到最前面。

更新了但没变化

pnpm 会按 lockfile 记住旧 commit：dsh plugin --profile web update dsh-whale-girl-live2d， 不行就 remove 再 add。
