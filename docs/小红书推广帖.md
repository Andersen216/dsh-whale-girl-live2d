## ★ GitHub 下载教程（正文里可以整段放，或做成第 10 张长图）

```
─────── 怎么从 GitHub 拿到它 ───────

先说明一下：这个插件不是「下载一个 exe 双击就完事」，
它是 DeepSeek Harness（DSH）的插件，所以要装在 DSH 里。
没装过 DSH 的话先去官网装好，能打开界面就行。

【方式一 · 一行命令（推荐）】
打开终端，复制这一行回车：

dsh plugin --profile web add github:Andersen216/dsh-whale-girl-live2d

看到安装完成，重启 DSH，刷新页面 —— 她就在右下角了。

【方式二 · 不碰命令行，手动下载 ZIP】
① 浏览器打开：
   github.com/Andersen216/dsh-whale-girl-live2d
② 右上角绿色按钮 Code → Download ZIP
③ 解压到一个记得住的目录，比如「文稿」里：
   /Users/你的名字/Documents/dsh-whale-girl-live2d
④ 打开终端（启动台搜「终端」），把下面这行的路径换成你解压出来的那个目录，回车：
   dsh plugin --profile web add "link:/Users/你的名字/Documents/dsh-whale-girl-live2d"
⑤ 重启 DSH、刷新页面，右下角出现鲸鱼娘就成功了。

【方式三 · 等插件市场上架后一键装】
DSH 设置 → 插件市场 → 搜 dsh-whale-girl-live2d → 点安装。

【只需要看看、不想装】
仓库页面直接能看介绍和截图，不用下载任何东西。

【装完这样验证】
· 右下角出现鲸鱼娘，鼠标移上去她旁边冒出三个小按钮（说话 / 菜单 / 隐藏）
· 点「⋯」能打开表情、装饰、场景、动作四页菜单
· 不想要了就卸载：dsh plugin --profile web remove dsh-whale-girl-live2d
```

### 常见卡点（发评论区置顶很好用）

| 现象 | 原因 / 怎么办 |
| --- | --- |
| `dsh: command not found` | DSH 没装或没进 PATH：先装 DSH，或用 `npx @deepseek-ai/dsh plugin ...` |
| 路径带空格报错 | 路径要用引号包起来：`"link:/Users/你/Documents/my folder/..."` |
| 装完了但看不见她 | **必须重启 DSH 再刷新页面**，插件是启动时加载的 |
| 页面刷新了还是旧样子 | 浏览器缓存：`Cmd + Shift + R` 强刷 |
| 想删掉 | `dsh plugin --profile web remove dsh-whale-girl-live2d` |
